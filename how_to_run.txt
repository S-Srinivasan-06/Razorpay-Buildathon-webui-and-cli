================================================================================
          RAZORPAY AUTONOMOUS FINANCIAL RECONCILIATION AGENT
                            HOW TO RUN
================================================================================

All project source code, datasets, tests, documentation, and Docker configuration
are located directly in the project root.

You can run the application using Docker (1-click, zero setup) or using Python locally.

--------------------------------------------------------------------------------
METHOD 1: DOCKER COMPOSE (FASTEST & RECOMMENDED - ZERO SETUP)
--------------------------------------------------------------------------------
Prerequisites: Docker & Docker Desktop installed and running.

1. Open your terminal in the repository root directory.

2. Start the containerized application:
     docker-compose up --build

3. Open your browser and go to:
     http://localhost:8000

   - The Web Console dashboard will load immediately.
   - All audit logs, uploads, and outputs persist automatically across container
     restarts in Docker volume 'recon_data'.

To stop the server:
     Press Ctrl + C (or run: docker-compose down)

--------------------------------------------------------------------------------
METHOD 2: LOCAL PYTHON (VIRTUAL ENVIRONMENT)
--------------------------------------------------------------------------------
Prerequisites: Python 3.10, 3.11, or 3.12+ installed.

1. Open your terminal in the repository root directory.

2. Create and activate a virtual environment:
   - On Windows (PowerShell):
       python -m venv .venv
       .venv\Scripts\Activate.ps1
   - On Windows (Command Prompt):
       python -m venv .venv
       .venv\Scripts\activate.bat
   - On Linux / macOS:
       python3 -m venv .venv
       source .venv/bin/activate

3. Install required dependencies:
     pip install -r requirements.txt

4. (Optional) Set your Gemini API key for live AI features:
   - Copy the example environment file:
       cp .env.example .env
   - Edit .env and enter your key:
       GEMINI_API_KEY=your_key_here
       LLM_MODEL=gemma-4-31b-it
   *Note: The engine works 100% offline in deterministic mode without any API key!*

5. Launch the Web Console Server:
     python -m src.app.server.main --host 127.0.0.1 --port 8000
   OR:
     python src/cli.py --server --host 127.0.0.1 --port 8000

   - Open your browser and navigate to:
       http://127.0.0.1:8000

--------------------------------------------------------------------------------
METHOD 3: RUN VIA TERMINAL COMMAND LINE (CLI)
--------------------------------------------------------------------------------
You can run automated reconciliations directly from the command line:

1. Standard Two-File Reconciliation (payments vs bank):
     python src/cli.py datasets/payments.csv datasets/bank.csv

2. Multi-Partner Ecosystem Reconciliation (5-File Supply Chain):
     python src/cli.py datasets/supply_chain_ecosystem/razorpay_x_ledger.csv datasets/supply_chain_ecosystem/hdfc_corporate_statement.csv datasets/supply_chain_ecosystem/icici_current_statement.csv datasets/supply_chain_ecosystem/urban_nest_po.csv datasets/supply_chain_ecosystem/megadist_invoice.csv

3. Pure Offline / Deterministic Mode (Zero-LLM, sub-second execution):
     python src/cli.py datasets/payments.csv datasets/bank.csv --deterministic

4. Benchmark Evaluation Against Ground Truth:
     python src/cli.py datasets/payments.csv datasets/bank.csv --truth datasets/ground_truth.jsonl

5. Interactive Grounded AI Chatbot in Terminal:
     python src/cli.py datasets/payments.csv datasets/bank.csv --chat

6. Export Output as Machine-Readable JSON:
     python src/cli.py datasets/payments.csv datasets/bank.csv --json

--------------------------------------------------------------------------------
METHOD 4: RUNNING THE AUTOMATED TEST SUITE
--------------------------------------------------------------------------------
Run the 42 test suites (unit, integration, end-to-end):

     pytest tests/ -v

--------------------------------------------------------------------------------
DIRECTORY OVERVIEW
--------------------------------------------------------------------------------
  src/                  - Core application source code
    app/core/           - State machine, SHA-256 audit, PII masking, LLM gateway
    app/engine/         - Matching engine, fee/tax rules, multiway chaining
    app/server/         - FastAPI server, REST API v2, WebSocket stream
    app/static/         - Single-Page Web UI (index.html)
    cli.py              - Unified terminal CLI runner
  datasets/             - Bundled benchmark datasets (payments, bank, 5-file ecosystem)
  data/                 - Runtime artifacts outside src (uploads, logs, audit, outputs)
  tests/                - Isolated test suite (tests/unit, tests/integration, tests/e2e)
  docs/                 - Architecture, Security & Audit, Hardening Post-Mortem
  Dockerfile            - Multi-stage slim Docker build
  docker-compose.yml    - 1-click Docker setup
  requirements.txt      - Pinned Python package dependencies
  README.md             - Full technical documentation & system blueprint
